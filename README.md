One word an agent says when it has no idea what to do: "Undefined" — a machine blurting out its own error value as a confession, the sound of an agent stalling. Chosen by a pairwise judge-simulator tournament over 16 candidate words against the brief's criteria in order (genuine one-word reaction, funny on its own, machine voice, lands instantly, fresh).

## Run it

```sh
python3 main.py
```
